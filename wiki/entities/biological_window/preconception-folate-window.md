# Preconception Folate Window

Biological window. The ~20-week period before conception during which RBC folate must rise to >1050 nmol/L for neural-tube-defect prevention. Starting only 3 months before trying risks inadequate folate when neural tube closes (days 22-28 post-conception, often before pregnancy is recognized).
